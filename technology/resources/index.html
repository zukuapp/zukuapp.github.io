ZWF2 명세가 정하는 검증·브라우저 경계와 실행 호스트가 정하는 자원 한도를 설명합니다.

ZWF2 명세의 요구 사항

패키지의 파일 경로·크기·해시 검증, 격리된 iframe, CSP, 브라우저 권한 거부가 ZWF2 플레이어 요구사항에 포함됩니다.

실행 호스트가 정하는 한도

CPU 코어 수, 메모리 용량, GPU 사용량, 프로세스 수의 한도는 실행 호스트가 정합니다. 브라우저 격리는 이런 자원을 결정적으로 제한하지 않습니다.
