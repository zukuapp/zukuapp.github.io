리소스 한도와 명세 범위

공개 ZWF2 명세가 보장하는 검증·브라우저 경계와, 별도 운영 정책이 필요한 자원 제한을 구분합니다.

공개 명세에 있는 것

패키지의 파일 경로·크기·해시 검증, 격리된 iframe, CSP, 브라우저 권한 거부가 ZWF2 플레이어 요구사항에 포함됩니다.

명세만으로 보장하지 않는 것

CPU 코어 수, 메모리 용량, GPU 사용량, 프로세스 수의 고정 할당량은 공개 ZWF2 명세의 보장이 아닙니다. 브라우저 격리는 이런 자원을 결정적으로 제한하지 않습니다. 구체적인 운영 한도가 필요하면 실행 호스트의 현재 정책을 별도로 확인해야 합니다.

CPU·메모리·프로세스 한도는 실행 환경마다 다를 수 있습니다. 패키지 형식 명세만으로 특정 수치를 약속하지 않습니다.
