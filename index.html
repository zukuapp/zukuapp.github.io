FIRST RUN

작동하는 경로에서 시작하세요.

공개 zwf 저장소의 테스트와 샘플을 사용해 로컬에서 패키지를 만듭니다. 서비스 계정이나 게시 권한은 필요하지 않습니다.

단계별 설명과 검사 결과 보기 ↗ 
git clone https://github.com/zukuapp/zwf.git
cd zwf
npm ci && npm test
zip -j hello.zip examples/hello/index.html
node src/cli.mjs compile hello.zip -o hello.zwf --title "Hello ZWF"
node src/cli.mjs inspect hello.zwf

READ THE STATUS

도구의 상태를 먼저 확인하세요.

실행 가능zwf는 저장소에서 설치해 로컬 컴파일·검사할 수 있습니다.

계약 공개Jump 스키마와 API 명세는 구현 인터페이스를 설명합니다. 운영 서비스 제공을 뜻하지 않습니다.

시제품zuku-cli의 명령은 현재 자리만 잡힌 상태입니다. 검증·패키징·업로드 결과로 사용하지 마세요.
