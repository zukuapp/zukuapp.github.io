Jump Studio

Jump Studio는 게임 작품을 관리하는 공간입니다. 패키지 형식과 로컬 검증 방법은 공개 개발 문서에서 확인하고, 등록·게시 기능의 현재 범위는 Studio에서 확인하세요.

studio 열기 ↗ Aist에서 생성 ↗
01

형식 선택

HTML5 ZIP의 ZWF2와 Jump 매니페스트 계약 중 작업 대상에 맞는 형식을 확인합니다.

02

로컬 검증

공개 zwf 컴파일러 또는 Jump 패키지 검증기로 파일 구조를 점검합니다.

03

Studio 확인

로그인 후 작품 등록과 게시 기능의 현재 지원 범위·제약을 확인합니다.

04

게시 절차

실제 심사와 공개 상태는 Studio에서 표시되는 안내를 따릅니다.
