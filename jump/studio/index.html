Jump Studio

Jump 허브가 플레이를 맡는다면, Jump Studio는 배급을 맡습니다. 패키지 검증, 심사, Game Cloud, 개발자 문서가 한곳에 모입니다.

studio 열기 ↗ Aist에서 생성 ↗
01

자격 · 사전 등록

프로젝트를 만들고 메타·채널을 정합니다.

02

패키지 업로드

HTML5 ZIP 또는 Jump 전용 패키지. 위험하거나 잘못된 구조는 거절합니다.

03

자동 검증

구조와 실행 한도, 외부 스크립트 등을 검사합니다. 검증 핵심 구현은 공개하지 않습니다.

04

심사 · 공개

승인되면 Jump 허브에 오르고, Thread에는 짧은 미리보기가 생깁니다.

클라우드

Game Cloud

세이브, 리더보드, 멀티 세션을 Studio에서 연결합니다.

개발

게임 API

키는 서버에만 두고, 버전과 인터페이스를 문서화합니다.
